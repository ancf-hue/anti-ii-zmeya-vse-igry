## 🎮 О проекте

**Snake Arcade** — это социальный офлайн-проект, объединяющий 6 уникальных 3D-игр про змею. Создан в противовес алгоритмам искусственного интеллекта — честный, живой геймплей для настоящих игроков.

## 🕹️ Игры в архиве

| # | Игра | Описание |
|---|------|----------|
| 🐜 | **Змея и Муравей** | Переползите через муравейник, не разбудив стражу |
| 🎵 | **Змея и Мелодия** | Музыкальная 3D-игра со светящимися плитками |
| 🫧 | **Змея и Пузыри** | Ломайте мыльные пузыри хвостом змеи |
| 🪰 | **Змея и Стрекоза** | Охотьтесь на проворную стрекозу в 3D-мире |
| 🐭 | **Змея и Мышка** | Поймайте мышку 3 раза за 3 минуты |
| 🍎 | **Змея и Яблоки** | Стеклянная змея собирает яблоки с подсветкой |

## 🏆 Доска почёта

Все игроки могут добавить свой результат через **защищённый код награды**, который генерируется в конце каждой игры. Это гарантирует честность таблицы лидеров.
